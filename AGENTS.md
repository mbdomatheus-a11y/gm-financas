# Contexto para qualquer IA que continuar este projeto

Este projeto é totalmente independente e não possui mais qualquer vínculo com a plataforma Lovable. A hospedagem oficial é na Vercel com banco Postgres e autenticação no Supabase.

Antes de começar, leia no Obsidian do Matheus (pasta `C:\Users\Usúario\Documents\OBSIDIAN\SEGUNDO CÉREBRO`):
1. `01 - PROJETOS/gm-financas-passagem-para-outra-ia.md` (estado atual, pendências, regras)
2. `01 - PROJETOS/gm-financas.md` (referência técnica completa)

Regras rápidas: nunca `git add -A`; evite force push; `npx tsc --noEmit -p tsconfig.json` antes do push;
alteração destrutiva no banco só com autorização do Matheus; tabela nova sempre com RLS;
respostas em português do Brasil, sem travessão, com checklist do que foi feito no fim.
Ao terminar, registre no fim de `01 - PROJETOS/gm-financas.md` o que mudou e o commit.
